XML ou DANFE: qual é a diferença?

Os dois apresentam dados da mesma nota, mas têm funções diferentes. Saber qual arquivo guardar evita problemas na conferência e na escrituração.

Atualizado em 5 de agosto de 2026 · Leitura de 4 minutos

O XML é o documento eletrônico

O XML reúne os dados estruturados da NF-e: identificação do emitente e do destinatário, itens, totais, tributos, transporte, pagamentos, chave e protocolo de autorização. Ele é assinado digitalmente pelo emissor e autorizado pela administração tributária.

Como o conteúdo segue um formato técnico, abrir o XML diretamente pode mostrar muitas tags. Isso não significa que o arquivo esteja errado; um visualizador apenas organiza essas informações para leitura.

O DANFE é uma representação auxiliar

DANFE significa Documento Auxiliar da Nota Fiscal Eletrônica. Ele apresenta uma seleção dos dados da NF-e em formato legível, inclui a chave de acesso e acompanha o trânsito da mercadoria quando exigido. O DANFE facilita a conferência, mas não substitui o XML.

Um PDF do DANFE pode ser refeito a partir do XML autorizado. O caminho inverso não funciona: o DANFE não contém toda a estrutura necessária para reconstruir o XML original assinado.

Qual arquivo devo guardar?

Guarde o XML original recebido do emissor ou do sistema fiscal. O DANFE pode ser mantido para consulta e impressão, mas não deve ser tratado como a única cópia do documento eletrônico.

Como conferir se o XML foi autorizado

  1. Localize a chave de acesso no arquivo ou no DANFE.
  2. Consulte a chave no Portal Nacional da NF-e.
  3. Confira a situação, o protocolo e os principais participantes.
  4. Se houver divergência, peça ao emissor o arquivo correto.

Eventos posteriores, como cancelamento, também devem ser considerados. Uma impressão antiga pode não refletir uma mudança ocorrida depois da autorização.

Quando usar cada um

  • Para importar no sistema contábil: use o XML.
  • Para conferir produtos de forma visual: use o DANFE.
  • Para imprimir ou acompanhar a mercadoria: use o DANFE conforme o caso.
  • Para confirmar a situação atual: consulte a chave no portal oficial.
