Erros comuns ao abrir um XML fiscal.

Nem todo arquivo com extensão XML é uma NF-e ou um CT-e completo. Aprenda a reconhecer os problemas mais frequentes antes de tentar novamente.

Atualizado em 5 de agosto de 2026 · Leitura de 5 minutos

O arquivo não é o documento autorizado

Uma operação fiscal pode gerar vários XMLs: nota, protocolo, cancelamento, carta de correção, manifestação, inutilização ou recibo. Para montar DANFE ou DACTE, a ferramenta precisa dos dados principais da NF-e ou do CT-e. Um XML contendo apenas um evento não possui itens, participantes e totais suficientes.

Procure no conteúdo elementos como infNFe para NF-e ou infCte para CT-e. Nos arquivos processados, também podem aparecer nfeProc ou cteProc.

O XML está incompleto ou malformado

Se o download foi interrompido, o arquivo pode terminar no meio de uma tag. Ele também pode ter sido copiado de um e-mail de forma incompleta ou salvo por um editor que alterou caracteres especiais.

Como verificar

  • Baixe novamente na origem.
  • Compare o tamanho com o arquivo enviado pelo emissor.
  • Abra apenas para leitura em um navegador ou visualizador confiável.
  • Não apague tags nem tente “corrigir” manualmente o documento fiscal.

A extensão não corresponde ao conteúdo

Renomear PDF, HTML ou texto para “.xml” não transforma o arquivo em XML fiscal. O mesmo vale para um ZIP que ainda não foi extraído. Confira a extensão real e, se o sistema esconder extensões, veja as propriedades do arquivo.

Arquivos fiscais podem conter dados comerciais e pessoais. Evite visualizadores desconhecidos e não publique o conteúdo em fóruns ou redes sociais.

O documento usa outro modelo

A NF-e de mercadorias normalmente usa o modelo 55, enquanto o CT-e usa o modelo 57. Outros documentos eletrônicos, como NFC-e, NFS-e e MDF-e, possuem estruturas próprias. Uma ferramenta voltada para DANFE e DACTE pode não interpretar esses outros formatos.

A chave ou os dados não batem

Se a chave encontrada no XML não tiver 44 posições, o arquivo pode estar truncado ou não corresponder a uma NF-e/CT-e. Se os dados visuais parecem diferentes dos esperados, consulte a chave no portal oficial e peça ao emissor uma nova cópia do XML.

No processamento em lote, um arquivo com erro não bloqueia necessariamente os demais. A lista mostra individualmente quais DANFEs ou DACTEs ficaram prontos.
