NF-e modelo 55 e NFC-e modelo 65: qual é a diferença?

Os dois documentos usam tecnologia eletrônica e possuem chave de acesso, mas foram criados para contextos diferentes. Saber o modelo evita tentar gerar um DANFE de NF-e a partir do arquivo errado.

Atualizado em 14 de agosto de 2026 · Leitura de 6 minutos

Modelo 55: a NF-e

A Nota Fiscal Eletrônica modelo 55 é amplamente usada para documentar operações com mercadorias. Seu XML contém dados de emitente, destinatário, produtos, tributos, totais, transporte e outras informações conforme a operação. Sua representação auxiliar é o DANFE.

Modelo 65: a NFC-e

A Nota Fiscal de Consumidor Eletrônica modelo 65 é voltada a operações de varejo ao consumidor final, dentro das regras adotadas por cada unidade federativa. Sua representação visual e o conjunto de informações esperadas não são iguais ao DANFE tradicional da NF-e modelo 55.

Como descobrir o modelo

A chave de acesso contém uma parte que identifica o modelo do documento. O próprio XML também informa o modelo. Em um arquivo válido, esses dados devem ser coerentes entre si.

65NFC-eDANFE NFC-e / representação própria
57CT-eDACTE

Por que um visualizador pode rejeitar o arquivo

Uma ferramenta pode ser construída para modelos específicos. O ProcurandoNFe atualmente reconhece NF-e modelo 55 e CT-e modelo 57 nos fluxos de DANFE e DACTE. Enviar um XML de NFC-e não deve ser tratado como se fosse NF-e modelo 55, porque a estrutura e a finalidade são diferentes.

Não renomeie o arquivo para tentar converter

Mudar a extensão ou o nome do arquivo não altera o modelo fiscal. Se você recebeu uma NFC-e e precisa de uma representação adequada, use uma solução compatível com o modelo 65 ou o canal oficial correspondente.
