3

PREPARE SEUS DADOS

Use Excel ou JSON como fonte de dados.

Você não envia arquivos ao site. O Excel ou JSON permanece no seu computador e é conectado diretamente ao dashboard pelo Power BI Desktop.

  • No Excel, use a primeira linha como título das colunas.
  • No JSON, mantenha os mesmos nomes de campos do modelo.
  • Não use células mescladas ou linhas vazias no Excel.
  • Informe valores como número, sem escrever “R$”.
  • Mantenha datas e nomes de campos no padrão indicado.

DÚVIDAS FREQUENTES

Antes de baixar um template.

Preciso enviar algum arquivo ao site?

Não. Você baixa o dashboard e conecta seu arquivo Excel ou JSON diretamente no Power BI Desktop instalado no seu computador.

Preciso ter o Power BI instalado?

Sim. Os templates serão preparados para o Power BI Desktop. O programa é necessário para abrir, atualizar e personalizar o dashboard.

Posso usar Excel ou JSON?

Sim. Cada template informará os nomes das colunas do Excel e dos campos do JSON que precisam ser mantidos para atualizar o dashboard.

Como informo os dados do Dashboard de Vendas?

Escolha um dos modelos e use os campos indicados. No Multicanal, por exemplo, informe Plataforma, Data, Quantidade, Receita, Custos e Taxas ou Débitos: Mercado Livre 25 vendas e Amazon 12 vendas. O lucro será calculado pelo dashboard. O site não acessa suas contas.

Qual a diferença entre Gratuito, Pessoal Pro e Profissional?

Gratuito é um modelo básico para uso pessoal. Pessoal Pro possui mais páginas, filtros e indicadores. Profissional é desenvolvido para empresas, equipes e atividades comerciais.
