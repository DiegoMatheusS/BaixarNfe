GERADOR DE QR CODE

Crie um QR Code a partir de um texto ou link.

Digite o conteúdo, gere o código e baixe em PNG. O texto informado é transformado em QR Code localmente no seu navegador.

Conteúdo do QR Code

Para links, inclua o endereço completo, como https://exemplo.com.br.

Processamento local

O texto digitado não precisa ser enviado ao servidor do site para montar o QR Code.

Links e textos

Você pode codificar endereços de sites, mensagens, códigos e outros textos curtos.

Teste antes de usar

Leia o QR Code com o celular antes de imprimir ou compartilhar em grande escala.
