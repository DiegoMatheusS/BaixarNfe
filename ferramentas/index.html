FERRAMENTAS ONLINE

Utilidades simples para resolver tarefas do dia a dia.

Use as ferramentas diretamente no navegador, sem cadastro. Conversão de imagens, QR Code e remoção de fundo são processados localmente no seu dispositivo; o conversor de moedas consulta uma fonte externa apenas para obter a cotação de referência.

↔MOEDAS

Conversor de moedas

Converta valores entre real, dólar, euro e outras moedas usando a cotação de referência mais recente disponível.

Abrir ferramenta → ▦QR CODE

Gerador de QR Code

Transforme um link ou texto em QR Code e baixe a imagem PNG. O conteúdo é processado no próprio navegador.

Abrir ferramenta → ✂IMAGEM

Remover fundo de imagem

Remova fundos lisos ou uniformes de uma imagem e exporte o resultado em PNG transparente.

Abrir ferramenta → ◫IMAGEM

Converter imagem

Converta imagens entre JPG, PNG e WEBP sem precisar enviar o arquivo para um servidor.
